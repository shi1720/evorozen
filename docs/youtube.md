## Description

A supplier promises a credit. The credit arrives, but it covers only part of the shortage. Remainder keeps the rest visible.

Try the app: https://remainder-desk.web.app
Source code: https://github.com/shi1720/evorozen

Built by Shivam Gupta for Evorozen Apex: NextGen AI Buildathon 2026.

Remainder is a supplier-credit desk for independent cafés, restaurants, and food retailers. It connects an invoice, a receiving record, and a supplier credit note so the owner can review the evidence, prepare a claim, and track the amount still outstanding.

This demo follows fictional Fern & Flour and Northstar Foods: $216 claimed, $144 in a verified credit note, and $72 still open. All sample businesses and documents are fictional. The final film shows real OpenAI inference in a normal account. It uses recorded actions and held screenshots for explanation; it does not use the precomputed sample replay.

AI integration: The app uses OpenAI GPT-5.4 mini for live analysis. Evorozen signed supplier memory was verified separately.

AI proposes document matches. Application code checks source quotations and calculates balances. The owner reviews and approves the claim. Optional Evorozen Neural Pulse memory stores signed, owner-reviewed supplier aliases. Its memory integration is separate from the sponsor's inference service.

A verified credit note is not a bank payment or confirmation that a credit was applied in the accounts. Remainder creates email drafts for the owner to send; it does not contact suppliers automatically.

Our initial go-to-market plan is a small pilot with independent operators and hospitality bookkeepers. The proposed price is $29 per location per month, subject to measured usage and support costs. No customer revenue or traction is claimed in this demonstration.
