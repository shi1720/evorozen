# Embedded document fonts

- `NotoSans-Regular.ttf` and `NotoSans-Bold.ttf`: existing document fonts, licensed under [SIL OFL 1.1](OFL.txt).
- `NotoSerif-Regular.ttf`: unmodified Noto Serif from the installed authoring runtime. Its embedded copyright is **Copyright 2022 The Noto Project Authors (https://github.com/notofonts/latin-greek-cyrillic)**. Licensed under [SIL OFL 1.1](OFL-NotoSerif.txt).

The PDF and proof-card builders use these files directly. They do not depend on macOS system fonts. The application's existing evidence-PDF font choices are unchanged.
